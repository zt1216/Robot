 开发踩坑记录


1.后坐力 “抽搐”—— 手感节奏不均
症状：单击开枪视角抽一下，连发时断断续续地抽
根因：抬升直接瞬移赋值，回弹使用平滑插值，两段动画节奏不一致
修复方案：抬升与回弹统一使用协程搭配 Mathf.MoveTowards 实现分段平滑；抬升步长设置 0.2，回弹步长设置 0.05，模拟踢枪快、回位慢的真实枪械手感

2.射击转动视角被 “橡皮筋” 拽回 —— 协程快照失效
症状：开枪之后手动转动视角，会被强制拽回开枪那一刻的角度
根因：后坐协程启动时记录了原始角度快照，玩家后续操作修改的视角不会更新这个快照，程序只会基于过期快照执行回拉逻辑
修复方案：玩家输入优先级最高；协程每帧检测鼠标轴输入，玩家一旦操作鼠标，直接终止协程，交出视角控制权
进阶隐患：只在回弹阶段做终止检测会留下开枪瞬间的逻辑盲区；连续开火会生成多个协程互相冲突拉扯。使用协程句柄配合 StopCoroutine，保证同一时刻只会运行一个后坐协程

3.敌人巡逻到点站桩不动 —— 两套距离判定不匹配
症状：敌人抵达巡逻点之后原地停止不动，场景内不存在障碍物阻挡
根因：NavMeshAgent 的 stoppingDistance 设置为 1.5，敌人距离目标还有 1.5 米就会刹车停止移动；业务逻辑判断到达点位的阈值写为 <=1f，永远无法满足条件。导航组件刹车参数与业务判断阈值不一致
修复方案：业务逻辑判断阈值修改为 2f，数值必须大于 stoppingDistance

4.随机巡逻点出界失效 —— 随机采样无视导航网格
症状：随机生成的巡逻点偶尔落在不可行走区域，敌人原地发呆卡死
根因：Random.insideUnitSphere 只做空间随机，不会识别 NavMesh 可行走区域
修复方案：使用 NavMesh.SamplePosition，采样半径设置 20，把随机生成的候选点吸附到导航可行网格上；采样失败时不设置移动目标，依靠下一帧重新随机点位完成容错

5.攻击状态敌人 “点头哈腰”——LookAt Y 轴高度陷阱
隐患：敌人和玩家模型高度不一致时，直接使用 LookAt (player.position)，会让敌人产生俯仰旋转，出现低头抬头的怪异效果
规避方案：复制玩家坐标，将 Y 值替换为敌人自身 Y 值，只做水平平面朝向；攻击状态关闭 agent.updateRotation，避免 NavMeshAgent 自动旋转和手动转向逻辑互相抢夺控制权
